## Objectius
Aquest exercici permet aplicar les ferramentes de GitHub a la gestió del treball d'aula.
En acabar, has de saber:

- Explicar què són les organitzacions de GitHub i quin ús se'ls pot donar en l'àmbit educatiu.
- Dissenyar un marc de treball amb GitHub per a gestionar el treball d'aula.


## Lliurament
!!! warning "No cal lliurar aquest exercici per a obtindre la certificació del curs."

Per a lliurar aquest exercici, tria una de les opcions següents:

=== "Document PDF"
    Documenta els passos realitzats en un document de text.

    - Inclou captures de pantalla amb els passos realitzats i els resultats obtinguts.

        > Retalla les captures de pantalla per mostrar només la informació rellevant.

    - Lliura el document en format __PDF__.

=== "Vídeo de la pantalla"
    Una vegada acabat l'exercici, grava un vídeo de la pantalla on mostres i expliques
    els passos realitzats i el resultat final.

    > No cal que apareguis en el vídeo, només la pantalla.

    - La durada __màxima__ del vídeo és de 10 minuts.


## Enunciat
Aquest exercici consisteix a dissenyar i posar en marxa un marc de treball per a una de les teues classes.

1. Utilitza les ferramentes que proporciona :simple-github: GitHub per a
    __dissenyar un marc de treball__ per a gestionar el treball d'aula d'un dels teus mòduls professionals.

    > Pots basar-te en alguna de les propostes de [[proposta-treball]].

2. Fes i documenta la __implementació inicial__ d'aquest marc de treball: crea una
    :octicons-organization-16: organització, :octicons-people-16: equips, etc.

3. Indica si creus que és viable incorporar-ho a l'aula amb el teu alumnat i quins avantatges
    i inconvenients creus que pot tindre aquesta manera de treballar.
