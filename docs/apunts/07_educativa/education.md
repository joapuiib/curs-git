## GitHub Education
[__:fontawesome-solid-graduation-cap: GitHub Education__](https://github.com/education) és una iniciativa
de GitHub adreçada a la comunitat educativa, que proporciona a l'alumnat i al professorat de centres educatius
accés gratuït a ferramentes i recursos de pagament.

!!! info "Per a obtindre aquests beneficis, cal sol·licitar l'accés en [GitHub Education application](https://education.github.com/discount_requests/application)."
    Cal una adreça de correu electrònic vàlida d'un centre educatiu o documentació que acredite
    la vinculació amb el centre.

### Beneficis per a l'alumnat
L'alumnat pot obtindre els beneficis del [__GitHub Student Developer Pack__](https://education.github.com/pack),
que inclou una àmplia varietat de ferramentes i serveis gratuïts. Aquests són alguns dels més destacats:

- [__GitHub Pro__](https://docs.github.com/es/get-started/learning-about-github/githubs-plans#github-pro):
    pla de pagament de GitHub amb accés a funcionalitats més avançades.
- [__:octicons-copilot-16: GitHub Copilot__](https://github.com/features/copilot):
    assistent d'intel·ligència artificial per a la programació.
- [__:octicons-codespaces-24: GitHub Codespaces__](https://github.com/features/codespaces):
    entorns de desenvolupament en línia basats en :material-microsoft-visual-studio-code: Visual Studio Code.
- __Llicències d'IDE de JetBrains__: inclou, entre altres, els entorns següents:
    - :simple-pycharm: __PyCharm Professional__ (Python).
    - :simple-intellijidea: __IntelliJ IDEA Ultimate__ (Java/Kotlin).
    - :simple-webstorm: __WebStorm__ comercial (JavaScript).
    - :simple-phpstorm: __PhpStorm__ (PHP).
- __Allotjament i dominis__: descomptes en serveis d'allotjament i de dominis.

!!! info "Més informació: [:octicons-link-external-16: GitHub Education Students](https://github.com/education/students) – :simple-github: GitHub"

### Beneficis per al professorat
El professorat també es pot beneficiar dels serveis de GitHub Education, que inclouen ferramentes
per a gestionar les classes i els projectes de l'alumnat:

- __Beneficis de l'alumnat__: tots els beneficis inclosos en el
    [__GitHub Student Developer Pack__](https://education.github.com/pack).

- [__GitHub Team__](https://github.com/team) per a l'educació: pla que inclou la gestió d'organitzacions.

    > La millora d'una organització a GitHub Team es pot sol·licitar en la pàgina
    > [GitHub Global Campus for Teachers](https://education.github.com/globalcampus/teacher).

!!! info "Més informació: [:octicons-link-external-16: GitHub Education Teachers](https://github.com/education/teachers) – :simple-github: GitHub"
