*[PR]: Pull Request

## Objectius
Aquest exercici permet practicar l'automatització de tasques amb GitHub Actions. En acabar, has de saber:

- Configurar fluxos de treball automatitzats amb GitHub Actions.
- Explicar el funcionament bàsic d'un flux de treball: esdeveniments, tasques (_jobs_) i passos.
- Adaptar un flux de treball a les necessitats d'un projecte concret.


## Lliurament
Per a lliurar aquest exercici, indica en la bústia d'Aules:

- __Repositori__: l'enllaç al repositori de :simple-github: GitHub.
- __Descripció__: una breu descripció del flux de treball creat, que indique:
    - Quin esdeveniment el desencadena (_push_, PR, etc.).
    - Quina tasca automatitza.
    - Quin resultat produeix.

El flux de treball s'ha d'haver executat almenys una vegada en el repositori, per a demostrar que funciona correctament.


## Enunciat
Crea un repositori de :simple-github: GitHub i automatitza una tasca relacionada amb aquest.
Pots triar qualsevol dels [[actions-exemples]] o bé investigar i crear una automatització pròpia.

Es recomana automatitzar alguna tasca d'un projecte que treballes a l'aula o que siga d'interés personal, com ara:

- __Proves__: execució automàtica de proves.
- __Estil__: verificació de l'estil del codi.
- __Documentació__: generació automàtica de documentació.
- __Desplegament__: desplegament en un entorn de proves.
